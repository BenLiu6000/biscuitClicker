Creates a sprite sheet on a javascript canvas which then can be saved. Its a bit finicky in order to run to get around cors policy and such. Firstly run server.js (not server.py) using node js. Afterwards run createSpriteSheet.html using localhost. The url when running should be something like http://localhost:{port number}/createSpriteSheet.html. You can achieve this through running python3 http.server {port number} in the createSpritesheet subdirectory.
